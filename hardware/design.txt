
Interface:
    Code Interface:
        - input   CODE.DATA[6:0]
        - input   CODE.STROBE      (* pulse input *)
        - output  CODE.LABEL[6:0]
        - output  CODE.SEEK        (* pulse output *)
        - output  CODE.HALT        (* pulse output *)

    Memory Interface:
        - output MEM.ADDR[7:0]
        - inout  MEM.DATA[7:0]
        - output MEM.CS
        - output MEM.OE
        - output MEM.WE

High-Level Components:
    IR[5:0]:  6 bit, Instruction Register
    OP[7:0]:  8 bit, Opcode Register
    ACC[7:0]: 8 bit, Accumulator Register
    ALU:      8 bit ROM with 19 bit addressing.

Data Movements + State Machine:
    state[fetch instruction]:
        when[CODE.STROBE]:
            IR <= CODE.DATA[5:0]                 (* truncate MSB *)
            goto state[fetch operand]
    state[fetch operand]:
        when[CODE.STROBE]:
            OP <= { IR[5], CODE.DATA }
            goto IR[4] ? state[indirect operand] : state[execute]
    state[indirect operand]:
        MEM.CS   <= 1
        MEM.OE   <= 1
        MEM.WE   <= 0
        MEM.ADDR <= OP
        OP       <= MEM.DATA
        goto state[execute]
    state[execute]:
        if IR[3]:
            ALU.ADDR <= {IR[2:0], ACC, OP}
            ALU.OE   <= 1
            ACC      <= ALU.DATA
        elif IR[2:0] == 0: (* HALT *)
            CODE.HALT <= 1 (* emit pulse *)
        elif IR[2:0] == 1: (* SET *)
            ACC      <= OP
        elif IR[2:0] == 2: (* LD *)
            MEM.CS   <= 1
            MEM.OE   <= 1
            MEM.WE   <= 0
            MEM.ADDR <= OP
            ACC      <= MEM.DATA
        elif IR[2:0] == 3: (* ST *)
            MEM.CS   <= 1
            MEM.OE   <= 0
            MEM.WE   <= 1
            MEM.ADDR <= OP
            MEM.DATA <= ACC
        elif IR[2]:
            CODE.LABEL <= OP[6:0];               (* truncate MSB *)
            if IR[1:0] == 0: (* JMP *)
                CODE.SEEK <= 1                   (* always emit pulse *)
            elif IR[1:0] == 1: (* JZ *)
                CODE.SEEK <= (ACC == 0)          (* emit pulse when zero *)
            elif IR[1:0] == 2: (* JNZ  *)
                CODE.SEEK <= (ACC != 0)          (* emit pulse when not zero *)
            else: (* DJNZ *)
                CODE.SEEK <= (ACC != 1)          (* emit pulse when not going to zero *)
                ALU.ADDR  <= { 3'b1, ACC, 8'b1 } (* subtract one *)
                ALU.OE    <= 1
                ACC       <= ALU.DATA
        goto state[fetch instruction]

Logic Formules and State Sequencing:
    This is the logic without *signal sequencing*, so no care for timing still.

    Add Components:
        STATE_FI: D-FlipFlop, Fetch Instruction
        STATE_FO: D-FlipFlop, Fetch Operand 
        STATE_IO: D-FlipFlop, Indirect Operand
        STATE_EX: D-FlipFlop, Execute

        OP_BUF:   3-State-Buffer, Operand
        ACC_BUF:  3-State-Buffer, Accumulator

    Reset State:
        STATE_FI.Q = 1
        STATE_FO.Q = 0
        STATE_IO.Q = 0
        STATE_EX.Q = 0
        ACC.Q      = 0 (* if not too much hassle *)

    Logic:
        ADVANCE_STATE <= (* synthetic advance pulse generated by monoflops *)
        CLK           <= CODE.STROBE | ADVANCE_STATE

        (* aliases for instructions *)
        OPCODE_ALU    <= STATE_EX.Q &  IR[3]
        OPCODE_HALT   <= STATE_EX.Q & !IR[3] & (IR[2:0] == 0)           (* provided by 1:8 demux *)
        OPCODE_SET    <= STATE_EX.Q & !IR[3] & (IR[2:0] == 1)           (* provided by 1:8 demux *)
        OPCODE_LD     <= STATE_EX.Q & !IR[3] & (IR[2:0] == 2)           (* provided by 1:8 demux *)
        OPCODE_ST     <= STATE_EX.Q & !IR[3] & (IR[2:0] == 3)           (* provided by 1:8 demux *)
        OPCODE_JMP    <= STATE_EX.Q & !IR[3] & (IR[2:0] == 4)           (* provided by 1:8 demux *)
        OPCODE_JZ     <= STATE_EX.Q & !IR[3] & (IR[2:0] == 5)           (* provided by 1:8 demux *)
        OPCODE_JNZ    <= STATE_EX.Q & !IR[3] & (IR[2:0] == 6)           (* provided by 1:8 demux *)
        OPCODE_DJNZ   <= STATE_EX.Q & !IR[3] & (IR[2:0] == 7)           (* provided by 1:8 demux *)

        STATE_FI.D    <= STATE_EX.Q
        STATE_FI.CLK  <= CLK

        STATE_FO.D    <= STATE_FI.Q
        STATE_FO.CLK  <= CLK

        STATE_IO.D    <= IR[4] ? STATE_FO.Q : 0                         (* mux 2:1 *)
        STATE_IO.CLK  <= CLK

        STATE_EX.D    <= IR[4] ? STATE_IO.Q : STATE_FO.Q                (* mux 2:1 *)
        STATE_EX.CLK  <= CLK

        BUS           <= ALU.DATA ~ MEM.DATA ~ OP_BUF.Q ~ ACC_BUF.Q     (* tristate join *)

        IR.D          <= CODE.DATA[5:0]
        IR.EN         <= STATE_FI.Q
        IR.CLK        <= CODE.STROBE

        OP.D          <= STATE_FO.Q ? { IR[5], CODE.DATA } : MEM.DATA
        OP.EN         <= STATE_FO.Q | STATE_IO.Q
        OP.CLK        <= CLK

        OP_BUF.D      <= OP.Q
        OP_BUF.OE#    <= !OPCODE_SET
        OP_BUF.OE2#   <= 'L'

        ACC.D         <= BUS
        ACC.EN        <= OPCODE_ALU | OPCODE_SET | OPCODE_LD | OPCODE_DJNZ
        ACC.CLK       <= CLK

        ACC_BUF.D     <= ACC.Q
        ACC_BUF.OE#   <= !OPCODE_ST
        ACC_BUF.OE2#  <= 'L'

        MEM.CS        <= STATE_IO.Q | OPCODE_LD | OPCODE_ST
        MEM.OE        <= STATE_IO.Q | OPCODE_LD
        MEM.WE        <= OPCODE_ST
        MEM.ADDR      <= OP.Q

        ALU.ADDR      <= OPCODE_ALU ? {IR[2:0], ACC, OP} : {3'b1, ACC, 8'b1} (* mux 2:1 *)
        ALU.OE        <= OPCODE_ALU | OPCODE_DJNZ

        CODE.LABEL    <= OP[6:0]
        CODE.SEEK     <= OPCODE_JMP | (OPCODE_JZ & (ACC==0)) | (OPCODE_JNZ & !(ACC==0)) | (OPCODE_DJNZ & !(ACC==1))
        CODE.HALT     <= OPCODE_HALT

Signal Phasing:

    For correct glitch-free operations, signals have to be activated/deactivated in
    a certain sequence to ensure correct operation.

    The signals in question are:
        MEM.ADDR[7:0]
        MEM.DATA[7:0]
        MEM.CS
        MEM.OE
        MEM.WE
        ALU.OE#
        ALUMUX[*].OE#
        ACC_BUF.OE#
        OP_BUF.OE#
        STATE_FF.CLK
        OP.CLK
        ACC.CLK
        IR.CLK
        OP.CLK
    
    For MEM, we assume a single static RAM like the AS6C1008-55PCN for time sequencing.

    Required signal sequencing:
        ALU Read:
            \ALU.CS#, >ALU.ADDR
            \ALU.OE#
            ALU.DQ=[01]
            /ALU.OE#, /ALU.CS#
            ALU.DQ=Z

        MEM Read:
            \MEM.CS#, >MEM.ADDR
            \MEM.OE#
            MEM.DQ=[01]
            /MEM.OE#, /MEM.CS#
            MEM.DQ=Z

        MEM.Write:
            \MEM.CS#, =MEM.ADDR
            \MEM.WE#, >MEM.DATA
            <MEM.DQ
            /MEM.WE#, /MEM.CS#
            ~MEM.DATA

        ALUMUX[*].OE#, ACC_BUF.OE#, OP_BUF.OE#
            OP_BUF.OE#
            <OP_BUF.Y

    Signal Phasing:
        Each clock is divided into 4 different time points:

        T1: IDLE    | idle phase, all current static control logic is applied.
        T2: READ    | all active output enables are enabled, all write enables are enabled
        T3: WRITE   | CLK is latched, all write enables are released
        T4: ADVANCE | all output enables are released, triggers the next stage transition, so also marks the T1 of the next CPU state

        T1 and T4 are the same point in time, but from a different perspective:
        A state is starting at T1 and ends in T4.

                T1  T2  T3  T4  
        SL      ´´´´´´´´´´´´´´´´    (* static logic *)
        OE#     ´´´´\_______/´´´    (* gate for OE# *)
        WE#     ´´´´\___/´´´´´´´    (* gate for WE# *)
        CLK     ________/´´´\___    (* the CLK signal *)
        ADV     /´´´\_______/´´´    (* the next phase advance trigger *)
    
        ADV is the "advance state" signal which triggers the STATE_FF through a positive edge.

        The T states are ordered like this:
        T1 happens when a new state is entered in STATE_FF.
        T2 happens when negedge(ADV) (~ 10 us after T4/T1) or posedge(CODE.STROBE) is detected
        T3 happens ~10 us after T2
        T4 happens ~20 us after T2, ~10 us after T3

        The OE# signal can be generated by a ~ 20 us monoflop, launched by (negedge(ADV) when (STATE_FF.Q[IO] | STATE_FF.Q[EX])) or posedge(CODE.STROBE)
        The WE# signal can be generated by a ~ 10 us monoflop, launched by (negedge(ADV) when (STATE_FF.Q[IO] | STATE_FF.Q[EX])) or posedge(CODE.STROBE)
        The CLK signal can be derived from the WE# signal, as the only required property is the position of the posedge(WE#)
        The ADV signal can be generated by a ~ 10 us monoflop, launched by posedge(OE#)

    Logic with timing:

        We need to rewire the following signals:

        STATE_FF.CLK    <= ADV                  (* triggers advancement on rising edge *)
        ACC.CLK         <= WE#                  (* we can use the deactivation event of WE# for also writing the flip-flops *)
        IR.CLK          <= WE#                  (* CODE.DATA is latched ~ 10 us after CODE.STROBE *)
        OP.CLK          <= WE#                  (* CODE.DATA is latched ~ 10 us after CODE.STROBE *)

        OP_BUF.OE2#     <= OE#
        ACC_BUF.OE2#    <= OE#
        ALUMUX[*].OE2#  <= OE#

        ALU.OE#         <= OE#                  (* rewrite to pure output enable)
        ALU.CS#         <= AND2.Y[3]            (* statically select the ALU in EX state *)

        MEM.OE#         <= AND2.Y[2]   | OE#    (* diode or for glitchless operation *)
        MEM.WE#         <= OPCODE_ST#  | WE#    (* diode or for glitchless operation *)

        CODE.SEEK#      <= AND4_2.Y[1] | WE#    (* diode or for glitchless operation *)

    New components:

        TIM1            => 1x CD74HC221E        (* provides OE# and WE# *)
        TIM2            => 1x CD74HC221E        (* provides ADV *)

    New high-level logic:

        (* negedge(ADV) when (STATE_FF.Q[IO] | STATE_FF.Q[EX])) or posedge(CODE.STROBE) *)
        TRIG_EXEC       <= CODE.STROBE | TIM2.2Q    (* trigger on rising edge of CODE.STROBE or the "edge inverter" monoflop for ADV *)
        
        (* configured for 20 us operation *)
        TIM1.1A#        <= 'L'                              (* for posedge() to work, this must be 'L' *)
        TIM1.1B         <= TRIG_EXEC                        (* trigger this monoflop when we get a posedge() *)
        TIM1.1R#        <= 'H'

        (* configured for 10 us operation *)
        TIM1.2A#        <= 'L'
        TIM1.2B         <= TRIG_EXEC                        (* trigger this monoflop when we get a posedge() *)
        TIM1.2R#        <= 'H'

        (* configured for 10 us operation *)
        TIM2.1A#        <= 'L'
        TIM2.1B         <= OE#                              (* ADV triggers on OE# )
        TIM2.1R#        <= 'H'

        (* we use the TIM2.2 as a "edge inverter", which triggers with a really short pulse *)
        TIM2.2A#        <= ADV                              (* trigger on negedge(ADV) *)
        TIM2.2B         <= 'H'                              (* idle state so we never trigger *)
        TIM2.2R#        <= STATE_FF.Q[IO] | STATE_FF.Q[EX]  (* diode or *)

        OE#             <= TIM1.1Q#                         (* posedge(CLK),  negedge(ADV) when state in {IO,EX} *)
        WE#             <= TIM1.2Q#                         (* posedge(CLK),  negedge(ADV) when state in {IO,EX} *)
        CLK             <= WE#                              (* we just "rename" the signal here *)
        ADV             <= TIM2.1Q                          (* posedge(OE#) *)
